# Project Rules

- When the local git configuration (`user.email` in `git config --local`) equals or contains `vaseniero@gmail.com`, ensure that the active GitHub user is switched to `vaseniero` using the command `gh auth switch --user vaseniero`.
- Ensure `.kilo`, `.venv`, and `.env` are added to `.gitignore` and kept ignored.
- When creating a Pull Request, always use the GitHub CLI (`gh`) and ensure to provide a clear title/summary and description.
